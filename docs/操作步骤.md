# OpenArm 真机 VR 操作步骤

当前硬件映射：

```text
can0 = 左臂
can1 = 右臂
```

只有反馈检查显示 `16/16` 时，才允许启动真机遥控。

## 1. 上电前

1. 清空机械臂工作范围，保证周围无人。
2. 准备可以立即切断机械臂 24V 电源的物理开关。
3. 确认左右 CAN 插头完全插紧。
4. 给两只机械臂上电，但暂时不要戴 Pico、不要按侧握键。

## 2. 配置 USB-CAN

USB-CAN 重新插拔后，`can0/can1` 会恢复为 `DOWN`，需要重新配置：

```bash
sudo ip link set can0 down
sudo ip link set can0 type can bitrate 1000000 dbitrate 5000000 fd on
sudo ip link set can0 txqueuelen 1000
sudo ip link set can0 up

sudo ip link set can1 down
sudo ip link set can1 type can bitrate 1000000 dbitrate 5000000 fd on
sudo ip link set can1 txqueuelen 1000
sudo ip link set can1 up
```

检查接口：

```bash
ip -brief link show can0
ip -brief link show can1
```

两路都必须显示 `UP`。

## 3. 检查 16 个电机

进入项目：

```bash
cd /mnt/data/清敏感知/Openarm/Openarm_lerobot
```

执行只读检查：

```bash
conda run --no-capture-output -n lerobot python scripts/check_feedback.py
```

正确结果必须包含：

```text
[left] online: 8/8
[right] online: 8/8
TOTAL online: 16/16
```

只要出现 `MISS` 或不是 `16/16`，立即停止，不要启动真机遥控。

## 4. 连接 Pico USB

检查 Pico：

```bash
adb devices -l
```

设备状态必须是 `device`，不能是 `unauthorized`。

建立 USB 端口转发：

```bash
adb reverse tcp:4443 tcp:4443
adb reverse --list
```

列表中应包含：

```text
tcp:4443 tcp:4443
```

## 5. 启动真机遥控

在电脑终端执行：

```bash
cd /mnt/data/清敏感知/Openarm/Openarm_lerobot
./scripts/start.sh robot --host 127.0.0.1 --port 4443
```

这一条命令会同时启动：

```text
Pico/TeleopXR -> PyRoki IK 求解器 -> LeRobot 安全控制 -> can0/can1
```

不需要再单独启动求解器或另开一个 IK 终端。

程序启动并连接 CAN 时不会自动使能电机。

如果提示端口被占用：

```bash
ss -ltnp 'sport = :4443'
```

先在旧程序终端按 `Ctrl+C`，确认旧程序退出后再重新启动。

CUDA/JAX 回退到 CPU 的警告可以忽略。

## 6. Pico 进入 VR

在 Pico 浏览器打开：

```text
https://localhost:4443
```

然后：

1. 首次访问时允许证书继续访问。
2. 点击 `VR Mode`。
3. 允许 VR 和手柄追踪权限。
4. 确认页面显示已经连接。
5. 双手柄保持稳定，先不要大幅移动。

## 7. 遥控操作

- 同时按住左右侧握键：开始真机控制。
- 第一次按住时，双臂只在当前实际位置使能；后续帧才开始跟随。
- 首次测试只缓慢平移几厘米，不要快速甩动或大幅旋转。
- 松开任意一个侧握键：双臂发送零速度并保持当前位置。
- 左右食指扳机控制对应夹爪；双臂验证完成前不要测试夹爪。

程序具有以下保护：

- 真实时间速度和加速度限制；
- Pico 控制数据超过 `0.25 s` 中断时，尝试失能双臂；
- 任一电机反馈持续超过 `0.25 s` 丢失时，尝试失能双臂；
- `Ctrl+C`、`SIGTERM`、`SIGHUP` 和发送线程异常时，重复发送失能；
- 退出时分别检查左右 8 个电机的失能回包。

## 8. 正常停止

1. 先松开任意一个侧握键。   
2. 让双手柄保持不动。
3. 在电脑终端按：

```text
Ctrl+C
```

终端应显示：

```text
left arm disable acknowledged by all motors
right arm disable acknowledged by all motors
```

如果没有看到两侧确认，或者机械臂仍然带力，立即物理断电。

停止后可再次只读检查：

```bash
conda run --no-capture-output -n lerobot python scripts/check_feedback.py
```

## 9. 异常处理

### 一只机械臂突然不动

1. 立即松开侧握键。
2. 不要继续尝试移动。
3. 如果另一只机械臂仍然带力或卡住，立即物理断电。
4. 重新执行 `scripts/check_feedback.py`。

CAN 已经完全断开的机械臂无法接收软件失能指令，只能物理断电。

### 某一路变成 0/8

1. 关闭机械臂电源。
2. 拔下并重新插入 USB-CAN 的 USB 线。
3. 重新执行第 2 节的 CAN 配置。
4. 重新上电并执行第 3 节的 `16/16` 检查。

### USB-CAN 重新插拔

重新插拔后必须重新配置 `can0/can1`，不能直接启动 VR。

## 10. 当前限制

- 独立物理急停尚未接入软件状态。
- USB-CAN 通道完全断开时，软件无法使故障侧电机失能。
- 其他关节尚未全部完成逐关节低速验证。
- 当前不要使用 `record` 模式进行正式数据采集。
