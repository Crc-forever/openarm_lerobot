# OpenArm 数据采集命令说明

## 标准命令

在项目目录中执行：

```bash
cd /mnt/data/清敏感知/Openarm/Openarm_lerobot

./scripts/record.sh \
  --dataset-task "示例" \
  --dataset-repo-id local/example \
  --num-episodes 2
```

脚本默认使用局域网连接 Pico，同时采集：

- 左右机械臂和夹爪的实际电机反馈；
- 最终发送给机械臂的动作；
- 两台普通 USB 相机画面；
- Aurora930 的 RGB 和深度画面。

## 标准命令中的参数

### `--dataset-task "示例"`

本次操作任务的文字描述，会写入数据集每一帧的 `task` 字段。

正式采集时应填写清楚，例如：

```bash
--dataset-task "拿起桌面上的水杯并放入托盘"
```

描述中有空格或中文时必须使用引号。

### `--dataset-repo-id local/example`

数据集标识，同时决定本地数据集目录名。

`/` 保存到本地时会转换成 `_`，所以：

```text
local/example
```

对应：

```text
data/local_example/
```

再次使用相同标识时，程序会尝试向原数据集追加 episode，不会覆盖已有
episode。只有机器人字段、摄像头字段和采集帧率都与原数据集一致时才允许
追加；配置不一致时程序会拒绝启动。

新增第二台普通相机后，旧的三路图像数据集与当前四路图像结构不兼容。
第一次使用新结构时应换一个新的标识，例如：

```bash
--dataset-repo-id local/example_four_cameras
```

### `--num-episodes 2`

本次运行需要成功保存的 episode 数量。

- 按 `X` 成功保存才计数；
- 按 `B` 放弃的不计数；
- 达到指定数量后，程序自动结束并正常失能机械臂；
- 该参数必须是大于零的整数。

## 其他可选参数

### `--pico-link network|usb`

选择 Pico 连接方式。

```bash
--pico-link network
```

局域网连接，也是默认方式。Pico 和电脑需要处于同一局域网。

```bash
--pico-link usb
```

USB 有线连接，需要 Pico 已开启并授权 ADB 调试。

### `--dataset-root DIR`

修改数据集保存根目录，默认是项目中的 `data/`。

示例：

```bash
--dataset-root /mnt/data/openarm_datasets
```

若同时使用 `--dataset-repo-id local/example`，最终目录为：

```text
/mnt/data/openarm_datasets/local_example/
```

### `--dataset-fps FPS`

设置数据集采集帧率，默认是 `15` FPS。

示例：

```bash
--dataset-fps 15
```

向已有数据集追加时，帧率必须与原数据集一致。

### `--no-camera-preview`

关闭电脑上的实时相机预览窗口，但仍然采集并保存相机数据。

```bash
--no-camera-preview
```

正常操作时建议保留预览，以便及时发现相机卡顿或断流。

## 可用环境变量

### `OPENARM_SCENE_CAMERA` 与 `OPENARM_SCENE_CAMERA_SECONDARY`

临时指定两台普通 USB 相机设备：

```bash
OPENARM_SCENE_CAMERA=/dev/video2 \
OPENARM_SCENE_CAMERA_SECONDARY=/dev/video4 \
./scripts/record.sh \
  --dataset-task "示例" \
  --dataset-repo-id local/example \
  --num-episodes 2
```

两台普通相机序列号相同，脚本默认使用 USB 端口对应的稳定
`/dev/v4l/by-path/` 路径进行区分。只有需要手动覆盖时才使用以上环境变量。

### `OPENARM_TELEOP_PORT`

修改 TeleopXR 服务端口，默认是 `4443`：

```bash
OPENARM_TELEOP_PORT=4444 ./scripts/record.sh \
  --dataset-task "示例" \
  --dataset-repo-id local/example \
  --num-episodes 2
```

### `OPENARM_PICO_LINK`

设置默认 Pico 连接方式，效果等同于 `--pico-link`：

```bash
OPENARM_PICO_LINK=usb ./scripts/record.sh \
  --dataset-task "示例" \
  --dataset-repo-id local/example \
  --num-episodes 2
```

命令行中的 `--pico-link` 优先于该环境变量。

## 采集时的手柄操作

- 右手柄 `A`：开始一个 episode；
- 右手柄 `B`：放弃当前 episode；
- 左手柄 `X`：保存当前 episode；
- 只有双侧握进入机械臂控制期间才会产生有效数据帧；
- 电脑本机会用英文语音播报采集状态。

正确操作顺序：

1. 按 `A` 开始；
2. 双侧握并完成一次实际遥操作；
3. 松开侧握；
4. 按 `X` 保存，或者按 `B` 放弃。

## 查看脚本帮助

```bash
./scripts/record.sh --help
```

语音播报说明。eg：
当前共有这些语音播报：

- 按 A 开始：
  `Recording episode 1.`
  意思：开始录制第 1 条。

- 录制中重复按 A：
  `Recording in progress. Press X to save, or B to discard.`
  意思：正在录制，按 X 保存，按 B 放弃。

- 操作尚未处理完：
  `Please wait. The previous operation is still in progress.`
  意思：请等待上一个操作完成。

- 开始失败：
  `Failed to start recording. Check the computer.`
  意思：开始录制失败，查看电脑。

- 保存或放弃操作失败：
  `Recording operation failed. Check the computer.`
  意思：录制操作失败，查看电脑。

- 未开始时按 B 或 X：
  `No recording is in progress.`
  意思：当前没有正在录制的数据。

- 按 B 放弃成功：
  `Episode discarded. Ready for the next episode.`
  意思：本条已放弃，等待下一条。

- 放弃时没有有效帧：
  `No valid data. Ready for the next episode.`
  意思：没有有效数据，等待下一条。

- 按 X 但没有有效帧：
  `No valid data. Episode was not saved.`
  意思：没有有效数据，保存失败。

- 按 X 保存成功：
  `Episode 1 saved. Ready for the next episode.`
  意思：第 1 条已保存，等待下一条。

- 最后一条保存成功：
  `Episode 2 saved. Recording complete.`
  意思：第 2 条已保存，全部采集完成。
