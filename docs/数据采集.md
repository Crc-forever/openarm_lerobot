# 数据采集

开始前完成 README 中的 Aurora930 额外环境安装，并把 Pico 与电脑连接到同一
局域网。

## 1. 连接机械臂

机械臂上电并插好两路 USB-CAN 后，在仓库根目录粘贴以下 8 行：

```bash
sudo ip link set can0 down
sudo ip link set can0 type can bitrate 1000000 dbitrate 5000000 fd on
sudo ip link set can0 txqueuelen 1000
sudo ip link set can0 up
sudo ip link set can1 down
sudo ip link set can1 type can bitrate 1000000 dbitrate 5000000 fd on
sudo ip link set can1 txqueuelen 1000
sudo ip link set can1 up
```

## 2. 采集命令

```bash
./scripts/record.sh \
  --dataset-task "拿起桌面上的水杯并放入托盘" \
  --dataset-repo-id local/pick_cup \
  --num-episodes 20
```

终端会显示 Pico 浏览器地址。打开地址、允许证书继续访问，再点击
`VR Mode`。

默认保存到 `data/local_pick_cup/`，采集 15 FPS 的以下内容：

- 双臂和夹爪的 16 路实际状态；
- 最终发送给机械臂的 16 路动作；
- 两台普通 USB 相机；
- Aurora930 RGB 和深度图。

## 3. 手柄操作

1. 右手柄 `A`：开始一个 episode；
2. 按住双侧握完成遥操作；
3. 松开侧握；
4. 左手柄 `X`：保存；右手柄 `B`：放弃。

采集启动后，Aurora930 RGB 会显示在 Pico 右前方的悬浮窗口中。用左手柄
射线指向窗口，边框变蓝后按住 `Y` 即可拖动；拖动时边框变绿，松开 `Y`
后窗口固定。必须先命中窗口再按 `Y`，按住 `Y` 后扫过窗口不会误吸附。
`Y` + `B` 仍保留为控制坐标系重置组合键。

保存数量达到 `--num-episodes` 后程序自动结束。手动结束时先松开侧握键，
再回到终端按 `Ctrl+C`，等待视频编码完成。

## 4. 常用参数

USB 连接 Pico：

```bash
./scripts/record.sh --pico-link usb \
  --dataset-task "任务描述" \
  --dataset-repo-id local/task_name \
  --num-episodes 20
```

修改保存位置：

```bash
./scripts/record.sh \
  --dataset-root /mnt/data/openarm_datasets \
  --dataset-task "任务描述" \
  --dataset-repo-id local/task_name \
  --num-episodes 20
```

手动指定两台普通相机：

```bash
OPENARM_SCENE_CAMERA=/dev/video2 \
OPENARM_SCENE_CAMERA_SECONDARY=/dev/video4 \
./scripts/record.sh \
  --dataset-task "任务描述" \
  --dataset-repo-id local/task_name \
  --num-episodes 20
```

完整参数：

```bash
./scripts/record.sh --help
```
