# 统一环境与 RTX 5090 部署

## 目录结构

```text
~/openarm_stack/
├── openarm_lerobot/       # 遥控、真机驱动、数据采集
│   ├── .venv/            # 唯一 Python 3.12 环境
│   ├── data/             # 保持原有数据存储位置
│   └── logs/
└── openarm_inference/     # 推理代码、模型、DINOv2 与 LeRobot 0.6.2 源码
    ├── checkpoints/
    ├── weights/
    └── lerobot_src/
```

推理项目不再创建第二个虚拟环境，统一使用
`openarm_lerobot/.venv`。LeRobot 从 `openarm_inference/lerobot_src` editable 安装，
版本固定为 0.6.2。

## 离线阶段

没有公网时只同步代码、工具链、厂商驱动源码、模型和权重。不要从
RTX 3060 车机直接复制 `.venv`：其 PyTorch CUDA 11.8 构建不是 5090 的目标环境，
且 venv 包含绝对路径。

## 联网后的安装顺序

1. 安装系统的 NVIDIA 驱动，重启后用 `nvidia-smi` 验证。
2. 安装 Git、ROS 2 Humble 等系统依赖，并使用已随局域网迁移的厂商包
   在本机重新编译 Aurora930（不复用其他机器的 `build/install`）：

   ```bash
   ./scripts/install_aurora930.sh \
     .vendor/aurora930/deptrum-ros-driver-aurora930-x86_64-0.2.10-source.tar.gz
   ```

3. 安装 Python 3.12 和 `python3.12-venv`；如果已解压离线 Python 环境则跳过。
4. 在 `openarm_lerobot` 目录执行：

   ```bash
   OPENARM_TORCH_INDEX_URL=https://download.pytorch.org/whl/cu128 \
     ./scripts/install.sh
   ```

5. 运行 `./scripts/preflight.sh --software-only`。
6. 分别做遥控、十秒采集和十秒推理验收。

`install.sh` 默认寻找同级 `openarm_inference/lerobot_src`。如果采用其他布局，
设置 `OPENARM_LEROBOT_SOURCE=/absolute/path/to/lerobot_src`。
如果已将 `offline/openarm-python312.tar.gz` 解压到 `openarm_lerobot/.venv`，
安装器会直接复用该 Python 3.12 环境，不再要求系统 `python3` 为 3.12。

## 兼容性结论

- TeleopXR 的 23 个自动测试在 LeRobot 0.6.0 和 0.6.2 下均通过。
- `BiOpenArmFollower`、`LeRobotDataset.create`、RGB/Depth encoder 及 feature utils
  在当前使用路径中签名一致。
- V5 `patch_policy` 只在 0.6.2 源码中存在，因此统一环境不得降级到 0.6.0。
- 项目使用带 GUI 的 `opencv-python`，不与 `opencv-python-headless` 混装。
